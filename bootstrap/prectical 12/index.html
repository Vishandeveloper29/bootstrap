Responsive Web Programming Design (RWPD)

This course covers building responsive websites using HTML, CSS and the Bootstrap framework, from basic grid concepts to advanced components and plugins.

Unit 1: Introduction to Bootstrap

Topics: Bootstrap setup, grid system, containers, typography.

  • Installing Bootstrap and linking files
  • Container vs container-fluid
  • Rows and columns

Summary: Covers the fundamentals needed to start building responsive pages with Bootstrap.

Unit 2: Grid System

Topics: Offset columns, column ordering, nesting columns.

  • 12-column responsive grid
  • Nesting grids inside columns
  • Reordering columns for different screen sizes

Summary: Deep dive into building complex, responsive page layouts.

Unit 3: Forms and Buttons

Topics: Form layouts, form controls, input groups, buttons.

  • Horizontal, inline and basic forms
  • Validation states
  • Button styles and groups

Summary: Explains how to design accessible and responsive forms.

Unit 4: Navigation Components

Topics: Navbars, tabs, pills, breadcrumbs, pagination.

  • Fixed top/bottom navbars
  • Dropdowns inside navigation
  • Tabs vs pills navigation

Summary: Focuses on components used to help users move around a website.

Unit 5: JavaScript Plugins

Topics: Modals, alerts, tooltips, popovers, scrollspy, collapse.

  • Using Bootstrap's built-in JS plugins
  • Triggering components via data attributes
  • Dynamic behaviour with jQuery

Summary: Introduces the interactive plugins that ship with Bootstrap.
